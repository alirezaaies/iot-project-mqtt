\section{مرجع کوتاه SQL}

SQL به‌عنوان زبان اصلی مدیریت داده‌ها در SQLite مورد استفاده قرار می‌گیرد. دستورات اصلی شامل CREATE، INSERT، SELECT، UPDATE و DELETE هستند.

\subsection{نمونه دستورات}

\begin{lstlisting}[language=SQL]
SELECT * FROM devices;
INSERT INTO sensors(name, type) VALUES ("دما", "temperature");
\end{lstlisting}
