\section{ساختار فعلی پایگاه داده}
پس از ساخت بخش ذخیره‌سازی، جدول‌ها، کلیدها، محدودیت‌ها و شماره نسخه ساختار در این بخش ثبت می‌شوند.

\section{دستورهای عیب‌یابی}
فقط دستورهای خواندنی و تأییدشده
\lr{SQL}
برای بررسی تعداد دستگاه‌ها، آخرین داده سنسور و وضعیت فرمان‌ها اضافه می‌شوند. هر دستور کامل داخل محیط
\lr{LTR}
قرار می‌گیرد.

\section{پشتیبان‌گیری و بازیابی}
فرمان‌های آزمایش‌شده برای پشتیبان‌گیری، بررسی سلامت و بازیابی فایل
\lr{SQLite}
همراه با مسیر فایل ثبت می‌شوند.
