\section{جدول موضوع‌ها}
پس از نهایی‌شدن قرارداد، برای هر
\lr{Topic}
نسخه، جهت پیام، فرستنده، گیرنده، سطح
\lr{QoS}
و وضعیت نگهداری پیام ثبت می‌شود.

\section{رفتار اتصال}
شناسه مشتری، زمان زنده‌ماندن اتصال، پیام قطع ناگهانی، روش احراز هویت و سیاست اتصال دوباره دقیقاً مطابق تنظیم پروژه نوشته می‌شوند.

\section{فرمان‌های عیب‌یابی}
فرمان‌های واقعی ارسال و دریافت که با
\lr{Mosquitto}
آزمایش شده‌اند، داخل محیط
\lr{LTR}
قرار می‌گیرند و نتیجه مورد انتظار آن‌ها نیز ثبت می‌شود.

\section{منبع مرجع}
برای جزئیات پروتکل از استاندارد رسمی
\lr{MQTT}
استفاده می‌شود و فقط تصمیم‌های مورد استفاده پروژه در این گزارش خلاصه می‌شوند.
