\section{نصب و راه‌اندازی اولیه}

برای اجرای پروژه، ابتدا باید ابزارهای پایه نصب شوند. این کار شامل نصب Python، Git، SQLite و broker MQTT می‌شود.

\subsection{قدم اول: نصب Python}

نسخه مناسب Python را از وب‌سایت رسمی دانلود و نصب کنید. سپس محیط مجازی پروژه را ایجاد کنید.

\subsection{قدم دوم: نصب MQTT Broker}

برای نمونه می‌توان از Mosquitto استفاده کرد. پس از نصب، سرویس broker را راه‌اندازی و وضعیت آن را بررسی کنید.

\subsection{قدم سوم: نصب وابستگی‌ها}

با استفاده از pip، کتابخانه‌های مورد نیاز مانند paho-mqtt و سایر ماژول‌ها نصب می‌شوند.
