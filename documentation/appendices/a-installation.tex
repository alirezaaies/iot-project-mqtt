\section{هدف}
این پیوست فقط فرمان‌های نصب و نسخه‌های تأییدشده در محیط واقعی پروژه را نگهداری می‌کند. راهنمای عمومی هر ابزار در اینجا تکرار نمی‌شود.

\section{اطلاعات محیط}
سیستم‌عامل، معماری پردازنده و نسخه دقیق ابزارهای زیر پس از نصب ثبت می‌شوند:

\begin{itemize}
    \item
    \lr{Python}
    \item
    \lr{SQLite}
    \item
    \lr{Mosquitto}
    \item
    \lr{Arduino IDE}
    \item
    \lr{XeLaTeX}
\end{itemize}

\section{فرمان‌های نصب تأییدشده}
فرمان‌های مخصوص سیستم‌عامل، ایجاد محیط مجازی و روش بررسی نصب هنگام اجرای مرحله محیط محلی به این بخش اضافه می‌شوند.

اگر یک فرمان کامل انگلیسی یا یک قطعه کد لازم باشد، به شکل زیر نوشته می‌شود:

\begin{LTR}
\begin{lstlisting}
python --version
\end{lstlisting}
\end{LTR}

\section{بررسی نهایی}
برای هر ابزار یک فرمان نمایش نسخه و یک تست کوچک اجرا و نتیجه آن ثبت می‌شود.
