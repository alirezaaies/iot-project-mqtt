\section{پیش‌نیازهای Python}

Python یکی از ابزارهای اصلی در این پروژه است و برای توسعه سرویس‌های نرم‌افزاری، پردازش داده، اتصال به MQTT و مدیریت پایگاه داده استفاده می‌شود.

\section{نسخه پیشنهادی}

نسخه 3.10 یا جدیدتر برای این پروژه مناسب‌تر است، زیرا ابزارها و کتابخانه‌های مورد نیاز معمولاً با نسخه‌های جدیدتر سازگاری بهتری دارند.
