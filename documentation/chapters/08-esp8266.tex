\section{ESP8266 چیست؟}

ESP8266 یک ماژول کم‌هزینه و بسیار محبوب برای پروژه‌های اینترنت اشیا است. این تراشه قابلیت اتصال به Wi-Fi را دارد و برای سنسورهای سبک و دستگاه‌های قابل کنترل به‌صورت گسترده استفاده می‌شود.

\section{مزیت‌ها}

\begin{itemize}
    \item هزینه کم
    \item مصرف انرژی مناسب
    \item پشتیبانی از Wi-Fi
    \item مناسب برای پروژه‌های آموزشی و صنعتی
\end{itemize}

\section{کاربرد در پروژه}

در این پروژه ESP8266 وظیفه جمع‌آوری داده‌های سنسورها و ارسال آن‌ها به broker MQTT را بر عهده دارد.
