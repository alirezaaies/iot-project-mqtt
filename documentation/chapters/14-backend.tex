\section{بک‌اند پروژه}

بک‌اند نقش اصلی در دریافت داده‌ها، ذخیره‌سازی، پردازش و ارائه سرویس‌ها به رابط‌های مختلف را دارد. در این پروژه، بک‌اند می‌تواند با Python و FastAPI یا Flask پیاده‌سازی شود.

\section{وظایف اصلی}

\begin{itemize}
    \item دریافت پیام‌ها از MQTT
    \item ذخیره‌سازی داده‌ها
    \item ارائه API برای وب‌اپ
    \item ارسال فرمان‌ها به دستگاه‌ها
\end{itemize}

\section{مسیرهای API}

API‌ها باید برای دستگاه‌ها، سنسورها، وضعیت‌ها و کنترل‌ها تعریف شوند و با روش‌های استاندارد HTTP پاسخ دهند.
