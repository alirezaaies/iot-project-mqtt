\section{تست و اعتبارسنجی}

برای اطمینان از کارکرد درست پروژه، باید تست‌هایی برای هر لایه اجرا شود. این تست‌ها شامل تست واحد، تست یکپارچه و آزمایش سیستم هستند.

\section{انواع تست}

\begin{itemize}
    \item تست عملکرد MQTT
    \item تست پایگاه داده
    \item تست API
    \item تست دستگاه و سنسورها
\end{itemize}

\section{نتیجه مطلوب}

در صورت اجرای درست تست‌ها، احتمال خطا در زمان استقرار به‌شدت کاهش می‌یابد و کیفیت پروژه افزایش می‌یابد.
