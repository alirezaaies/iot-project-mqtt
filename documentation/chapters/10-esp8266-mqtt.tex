\section{ارسال داده به MQTT}

بعد از اتصال به Wi-Fi، ESP8266 باید به MQTT broker متصل شود و داده‌ها را روی موضوع‌ها ارسال کند. این مرحله مهم‌ترین بخش ارتباطی پروژه است.

\section{موضوع‌های پیشنهادی}

\begin{itemize}
    \item iot/device/status
    \item iot/sensor/temperature
    \item iot/sensor/humidity
    \item iot/device/control
\end{itemize}

\section{پیاده‌سازی ساده}

برای ارسال پیام، دستگاه باید اتصال را برقرار کند و در هر بازه زمانی، داده‌ها را به‌صورت JSON یا متن ساده روی موضوع مورد نظر منتشر کند.
