\section{قابلیت اطمینان}

سیستم IoT باید در شرایط نامنظم شبکه یا خرابی دستگاه‌ها، عملکرد خود را حفظ کند. بنابراین طراحی برای مقاومت در برابر خطا اهمیت زیادی دارد.

\section{روش‌های افزایش اطمینان}

\begin{itemize}
    \item ثبت لاگ‌ها
    \item مدیریت خطا و Retry
    \item استفاده از broker مقاوم
    \item ذخیره‌سازی داده‌های موقت
\end{itemize}

\section{نمونه وضعیت‌های خطا}

عدم اتصال به شبکه، قطعی broker، خطای سنسور، گلوگاه در پایگاه داده و زمان‌بندی نامنظم همه از سناریوهای معمول در پروژه‌های IoT هستند.
