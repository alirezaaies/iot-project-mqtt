\section{اهمیت Git}

Git ابزار اصلی برای مدیریت نسخه‌ها، همکاری تیمی و ردیابی تغییرات در پروژه است. با استفاده از Git، می‌توان هر مرحله از توسعه را ثبت و در صورت نیاز به نسخه‌های قبلی بازگشت انجام داد.

\section{مراحل پایه}

\begin{itemize}
    \item راه‌اندازی مخزن
    \item ایجاد شاخه‌ها
    \item ثبت تغییرات
    \item هماهنگی با ریموت
    \item بررسی تاریخچه پروژه
\end{itemize}

\section{روش استفاده در پروژه}

هر بخش از پروژه مانند ماژول‌های سخت‌افزاری، بک‌اند، وب‌اپ و مستندات باید در شاخه یا مسیر مشخص نگهداری شود تا همکاری تیمی و مدیریت نسخه‌ها ساده‌تر شود.
