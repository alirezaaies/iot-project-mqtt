\section{هدف پروژه}
هدف نهایی، ساخت سامانه‌ای محلی برای دریافت داده از سخت‌افزار، نگه‌داری داده، نمایش گزارش و ارسال فرمان کنترل است. پروژه مرحله‌به‌مرحله ساخته می‌شود تا هر بخش پیش از اتصال به بخش بعدی به‌تنهایی قابل آزمایش باشد.

\section{قواعد توسعه}
\begin{itemize}
  \item فقط فایل و پوشه‌ای ساخته می‌شود که در مرحلهٔ جاری استفاده شود.
  \item هر مرحله باید ورودی، خروجی و آزمایش مستقل داشته باشد.
  \item اطلاعات محرمانه مانند رمز شبکه وارد
  \lr{Git}
  نمی‌شود.
  \item ابتدا راه اجرای مرحله نوشته می‌شود؛ سپس کد مطابق همان راه اجرا پیاده‌سازی و آزمایش می‌شود.
  \item قابلیت تازه فقط زمانی اضافه می‌شود که مرحلهٔ قبلی کار کند.
\end{itemize}

\section{وضعیت فعلی}
نسخهٔ کنونی مسیر زیر را پیاده‌سازی می‌کند:

\begin{LTR}
\begin{lstlisting}
Sensors -> ESP8266 -> MQTT -> Collector -> SQLite
                         ^
                         |
                  Command sender
\end{lstlisting}
\end{LTR}

برد دما و رطوبت شبیه‌سازی‌شده را در قالب بسته‌های قابل‌توسعه منتشر می‌کند.
\lr{collector}
پیام معتبر را دریافت و هر
\lr{reading}
را در جدول مناسب ذخیره می‌کند.
فرستندهٔ
\lr{command}
نیز یک یا چند فرمان را به برد می‌فرستد و پاسخ مرتبط را دریافت می‌کند. حسگر فیزیکی و گزارش تصویری هنوز اضافه نشده‌اند.

\section{مراحل پروژه}
\begin{enumerate}
  \item آزمایش کارگزار و انتشار دادهٔ آزمایشی از برد؛
  \item دریافت و ذخیرهٔ پیام‌های معتبر در
  \lr{SQLite}
  با دو ماژول مستقل؛
  \item خواندن و نمایش داده با یک برنامهٔ کوچک
  \lr{Python}
  ؛
  \item \textbf{مرحلهٔ جاری:} ارسال یک یا چند فرمان امن و دریافت پاسخ هر
  \lr{action}؛
  \item ساخت رابط وب ساده برای پایش و کنترل؛
  \item افزودن گزارش، آزمون‌های یکپارچه و تنظیمات امنیتی نهایی.
\end{enumerate}

فصل‌های مراحل آینده زمانی به سند افزوده می‌شوند که پیاده‌سازی آن‌ها آغاز شود. بنابراین عنوان خالی یا توضیح فرضی در سند نگه‌داری نمی‌شود.

\section{معیار پایان مرحلهٔ جاری}
مرحله زمانی کامل است که:

\begin{itemize}
  \item پایگاه داده بدون نیاز به شبکه ساخته شود؛
  \item پیام ناقص پیش از ذخیره رد شود؛
  \item یک بستهٔ دو سنسوری به یک ردیف بسته و دو ردیف
  \lr{reading}
  تبدیل شود؛
  \item
  \lr{collector}
  پس از اتصال مجدد دوباره روی موضوع داده
  \lr{subscribe}
  کند؛
  \item دادهٔ ذخیره‌شده با فرمان مستقل قابل مشاهده باشد.
\end{itemize}
