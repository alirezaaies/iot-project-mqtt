# Web Application

Put the Flask application here, including routes, HTML templates, CSS, JavaScript, and HTTP API code.

The web application should request operations from the backend and should not communicate directly with ESP8266 or contain scattered SQL queries.

If Flask is replaced with Django later, this directory can be rebuilt while `backend/`, `database/`, `arduino/`, and `contracts/` remain mostly unchanged.

Create `templates/` and `static/` only when the first page is implemented.
